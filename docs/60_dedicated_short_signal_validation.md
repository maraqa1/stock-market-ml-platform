# Dedicated Short Signal Validation

The platform's short signals come from the bottom tail of the cross-sectional ranker, not from a dedicated short model. This diagnostic keeps short candidates research-only while measuring whether bottom-ranked names actually produce profitable short outcomes.

The report writes candidate-level short outcomes, bucket performance, inverse-long comparison, squeeze-risk flags, and a summary recommendation. It does not submit orders, change model scoring, loosen gates, increase exposure, or enable live trading.
